# E-Surat PKL · SMK Negeri 1 Sungai Rumbai

Aplikasi web untuk membuat surat permohonan PKL (kertas F4) dalam format PDF.
Isi tujuan, periode, dan daftar siswa, lalu unduh PDF. Surat otomatis masuk Arsip.

- Berjalan sepenuhnya di browser, tanpa server.
- Arsip tersimpan di browser pengguna (localStorage), bukan di GitHub.
- Satu file: `index.html`.
